# История изменений

## Экспериментальная разработка

- Добавлена отдельная обработка подписей в диалоге добавления подписки:
  тип, имя, URL, переключатели и закрытие. Действия и значения не изменяются.

- Исправлено распознавание возврата из «Пинга», когда OCR разделяет строку пути
  на соседние фрагменты. Точное название и проверки перед нажатием сохранены.

- Исправлено распознавание User agent: расширена область контекста, для заголовка
  выбирается установленный английский OCR с возвратом к русскому при отсутствии.
- Tab пропускает скрытые элементы, полностью вышедшие за вертикальные границы
  своей группы; названия для таких элементов не придумываются.

- Добавлена подпись редактора User agent по точному заголовку над полем,
  без сопоставления с содержимым редактора.

- Исправлена отмена распознавания подписей при разворачивании широкого окна:
  ограничивается область чтения слева, а не допустимая ширина окна.

- Добавлено экспериментальное название меню правил маршрутизации по точному
  распознанному заголовку и проверенной структуре страницы.

- Исправлен пропуск редакторов, у которых пустое имя UIA отличается от отсутствующего
  имени NVDA. Для OCR теперь читается левая область группы, а не тесная обрезка строки.
- Добавлен ограниченный пропуск скрытых дублей при Tab/Shift+Tab внутри настроек;
  чужие окна и обычные вложенные элементы не считаются дублями.
- Подтверждён возврат с подстраницы масштаба к главным настройкам.

- В список групп добавлен экспериментальный пункт «Назад к настройкам», когда
  над параметрами точно распознана строка пути известной вложенной страницы.
  Возврат с подстраницы масштаба проверен; остальные подстраницы ещё требуют проверки.

- Подтверждены озвучка списка групп и переход в «Настройки интерфейса» после
  исправления повторной проверки границ. Фокус на параметре ещё требует проверки.

- Исправлена отмена выбора группы при изменении её границ после закрытия списка:
  новые границы считываются перед повторным распознаванием той же подписи.

- Добавлена экспериментальная команда выбора видимых заголовков групп настроек
  без сочетания по умолчанию. Перед нажатием повторно проверяются локально
  распознанная подпись и геометрия. Реальная работа команды ещё не подтверждена.

- Чтение подписи расширено на текстовые и числовые поля настроек.
- Исправлена проверка списков: попадание на их вложенный текстовый элемент
  больше не считается перекрытием. Перекрытие посторонним полем по-прежнему
  отклоняется, чтобы скрытым полям не назначались чужие подписи.

- Добавлено экспериментальное локальное чтение подписей слева от переключателей
  и списков в группах настроек. Состояние сохраняется из Happ; поздний результат
  после смены фокуса не озвучивается. Проверка реальной речи ещё не завершена.

- Добавлена контекстная подпись «Поиск серверов».
- Добавлена контекстная подпись «Меню списка серверов».
- При неизвестном интерфейсе сохраняются исходные названия элементов.
- Добавлена экспериментальная команда NVDA+Alt+N для раскрытия боковой панели.
- Неработающее действие UIA кнопки панели заменено щелчком по её текущим границам
  с проверкой элемента под указателем, активного окна и состояния сеанса.
  Проверено раскрытие панели в Happ 1.2.4 (376); доступность её разделов ещё в работе.
- После раскрытия обнаружены шесть одинаковых безымянных кнопок панели.
  Сворачивание пока не поддерживается.
- На раскрытой панели NVDA+Alt+N открывает экспериментальный доступный список
  точно распознанных разделов. Используется локальное распознавание Windows
  на русском языке; совпадения проверяются по границам кнопок.
- Подтверждены озвучка списка разделов и открытие страницы «Настройки».
- Добавлены подписи языка и темы для проверенной группы со значениями
  «Русский» и «Системная», без изменения самих настроек.
