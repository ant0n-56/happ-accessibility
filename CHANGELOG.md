# История изменений

## Экспериментальная разработка

- Добавлена контекстная подпись «Поиск серверов».
- Добавлена контекстная подпись «Меню списка серверов».
- При неизвестном интерфейсе сохраняются исходные названия элементов.
- Добавлена экспериментальная команда NVDA+Alt+N для раскрытия боковой панели.
- Неработающее действие UIA кнопки панели заменено щелчком по её текущим границам
  с проверкой элемента под указателем, активного окна и состояния сеанса.
  Проверено раскрытие панели в Happ 1.2.4 (376); доступность её разделов ещё в работе.
- После раскрытия обнаружены шесть одинаковых безымянных кнопок панели.
  Повторная команда не выбирает их наугад; сворачивание пока не поддерживается.
