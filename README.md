# Доступность Happ для NVDA

Дополнение помогает пользоваться Happ с клавиатуры: озвучивает названия элементов, открывает список разделов и групп настроек, позволяет выбирать видимые серверы и действия подписки.

Автор: Anton Chigarev. Лицензия: MIT.

## Скачать и установить

[Скачать дополнение 0.1.1](https://github.com/ant0n-56/happ-accessibility/releases/download/v0.1.1/happAccessibility-0.1.1.nvda-addon).

1. Откройте скачанный файл `.nvda-addon`.
2. Подтвердите установку в NVDA.
3. Перезапустите NVDA.

Для обновления установите новый пакет поверх предыдущего и перезапустите NVDA.

## Требования

- Windows 11, Happ 1.2.4 с русским интерфейсом.
- NVDA 2026.1, включая обновления 2026.1.x.
- Русский язык распознавания текста Windows. Английский язык распознавания помогает читать латинские названия серверов.
- Для доступа к Happ, запущенному от имени администратора, используйте установленную NVDA.

## Команды

Команды работают в активном окне Happ. Клавиша NVDA — Insert или Caps Lock, в зависимости от ваших настроек.

- **NVDA+Alt+N** — раскрыть боковую панель или выбрать раздел из списка.
- **Выбрать видимый заголовок группы настроек Happ** — перейти в группу настроек или вернуться из неё.
- **Выбрать видимый сервер Happ из распознанного списка** — открыть список серверов.
- **Открыть действия подписки, на кнопке которой находится фокус** — открыть список действий нужной подписки.

Только первая команда имеет сочетание по умолчанию. Для остальных назначьте удобные клавиши:

1. Перейдите в Happ.
2. Откройте меню NVDA → Параметры → Жесты ввода.
3. В категории «Happ» выберите команду и добавьте сочетание.

Например: NVDA+Alt+G для групп настроек, NVDA+Alt+S для серверов, NVDA+Alt+A для действий подписки. Пока вы не назначите эти сочетания, они не действуют.

## Переход между разделами

Нажмите NVDA+Alt+N и отпустите клавиши. Если боковая панель закрыта, команда раскроет её. Нажмите сочетание ещё раз, чтобы открыть список «Разделы Happ».

Выберите раздел стрелками и нажмите Enter. Escape закрывает список без выбора. Доступны распознанные пункты «Добавить», «Серверы», «Настройки», «Статистика» и «Логи».

## Настройки

На странице «Настройки» вызовите команду выбора группы. Стрелками выберите нужную группу и нажмите Enter.

Поддерживаются группы «Настройки интерфейса», «Правила маршрутизации», «Дополнительные настройки», «Подписки» и «Пинг». На вложенной странице та же команда предлагает «Назад к настройкам», если строка возврата распознана.

Внутри группы перемещайтесь клавишами Tab и Shift+Tab. Дополнение добавляет названия полям, спискам и переключателям. Для распознавания подписи после перехода на элемент может понадобиться небольшая пауза.

В диалоге добавления конфигурации типа «Подписка» озвучиваются названия полей и переключателей.

## Выбор сервера

1. Откройте раздел «Серверы» с развёрнутой подпиской.
2. Вызовите команду выбора видимого сервера.
3. В списке «Серверы Happ» выберите название стрелками.
4. Нажмите Enter для выбора или Escape для отмены.

Выбор другого сервера может изменить текущее VPN-подключение.

## Действия подписки

1. В разделе «Серверы» клавишей Tab перейдите к кнопке «Меню подписки» нужной подписки. Не путайте её с «Меню списка серверов».
2. Вызовите команду действий подписки.
3. Выберите «Обновить подписку», «Пинг подписки» или «Меню подписки» и нажмите Enter.

Для обновления и пинга появится отдельный запрос подтверждения. По умолчанию выбран ответ «Нет». Обновление запрашивает данные подписки и может изменить список серверов; пинг отправляет запросы к серверам. Открытие списка само по себе эти действия не запускает.

## Подключение и отключение VPN

Используйте меню значка Happ в области уведомлений Windows:

1. Нажмите Windows+B и найдите Happ стрелками.
2. Нажмите Shift+F10.
3. Выберите «Подключиться» или «Отключиться» и нажмите Enter.

Escape закрывает меню без выполнения действия.

## Особенности и ограничения

- Часть названий читается распознаванием текста. Окно Happ должно быть открыто и не перекрыто другими окнами.
- В списки попадают только видимые распознанные элементы. Команды не прокручивают страницы и не раскрывают свёрнутые подписки.
- Перед выбором сервера проверьте его название: распознавание может ошибаться.
- При смене окна или расположения элементов действие может отмениться. Вернитесь в Happ и вызовите команду снова.
- Сообщение «Нажатие отправлено» означает отправку действия, а не подтверждение его результата.
- Отдельной команды для большой кнопки подключения нет. Пункт «О программе» и сворачивание боковой панели через список разделов не поддерживаются.
- Версия предварительная: дополнение не обеспечивает доступность всех элементов Happ.

Распознавание выполняется на компьютере средствами Windows. Дополнение не сохраняет снимки и распознанный текст и не отправляет их внешним сервисам.

## Если команды не работают

- Убедитесь, что дополнение включено в менеджере дополнений NVDA, и перезапустите NVDA после установки.
- Проверьте, что активно окно Happ, а нужной команде назначено сочетание.
- Если ранее устанавливали другой модуль поддержки Happ, удалите или отключите его: две реализации могут конфликтовать.
- Если список пуст или подписи не распознаются, убедитесь, что нужная часть окна видна и в Windows установлен русский язык распознавания.

## Удаление

В менеджере дополнений NVDA выберите «Доступность Happ — тестовая версия», нажмите «Удалить» и перезапустите NVDA. Для временного отключения выберите «Отключить».
