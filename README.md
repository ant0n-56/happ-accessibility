# Доступность Happ для NVDA

Автор: Anton Chigarev.

Экспериментальный модуль для Happ под Windows. Работа над полной доступностью
приложения продолжается; текущий модуль исправляет две подписи на странице
серверов с русским интерфейсом и добавляет экспериментальную навигацию по панели:

- поле ввода: «Поиск серверов»;
- кнопка меню справа от поиска: «Меню списка серверов».

Существующие названия, действия кнопок, переключатели TUN/Прокси и порядок Tab
сохраняются. Модуль не переключает подключение и не читает файлы подписок.

## Совместимость и состояние

Целевая проверяемая среда: Happ 1.2.4 (376), NVDA 2026.1.1 x64,
Windows 11. Другие версии и языки пока не проверены.
Это исходники экспериментального модуля, а не готовый стабильный выпуск.
Установочного файла `.nvda-addon` пока нет.

## Установка для испытаний

Используйте отдельный тестовый профиль NVDA. Скопируйте каталог
`addon/appModules/happ` в `scratchpad/appModules` этого профиля.
В дополнительных настройках NVDA включите загрузку пользовательского кода
из каталога разработчика, затем перезапустите тестовый NVDA.
Для Happ, работающего с правами администратора, нужен штатный установленный
NVDA с поддержкой UIAccess.

## Начало работы

1. Откройте Happ и страницу серверов.
2. Нажимайте Tab до сообщения «Поиск серверов, редактор».
3. После двух следующих нажатий Tab ожидается «Меню списка серверов, кнопка».
4. Пробел открывает штатное меню; Escape закрывает его.

Для возврата к предыдущему элементу используйте Shift+Tab.

## Боковая панель

В главном окне Happ нажмите **NVDA+Alt+N** и отпустите клавиши.
NVDA находит кнопку боковой панели через UI Automation и щёлкает по её текущим
границам. В Happ 1.2.4 проверено раскрытие панели этим способом: штатное действие
UIA не раскрывало её, а кнопка не принимала клавиатурный фокус.
Появляются разделы «Добавить», «Серверы», «Настройки», «Статистика», «Логи»
и «О программе».

Команда ждёт отпускания клавиш не более двух секунд, проверяет активное окно
и элемент под точкой нажатия. При перекрытии кнопки щелчок отменяется.
Исходное положение указателя восстанавливается, если указатель не был перемещён.
Сообщение «Щелчок по кнопке панели отправлен» подтверждает отправку нажатия,
а не проверку состояния панели. Команда остаётся экспериментальной.

### Выбор раздела

Когда панель раскрыта, повторное **NVDA+Alt+N** читает её видимые подписи
встроенным распознаванием Windows и открывает стандартный список «Разделы Happ».
Выберите пункт стрелками и нажмите Enter; Escape отменяет выбор.
В список включаются только точно распознанные «Добавить», «Серверы», «Настройки»,
«Статистика» и «Логи», если текст целиком расположен внутри одной найденной кнопки.
Отсутствующий в результате пункт не подставляется по порядку кнопок.

Нужен установленный русский язык распознавания Windows. Изображение панели
обрабатывается на компьютере; внешние сервисы не используются, снимки и результат
не сохраняются. Распознавание ограничено пятью секундами; смена окна отменяет
показ результата. При изменении положения кнопки выбор нужно повторить.
Панель должна быть видна и не перекрыта другим окном.

Сворачивание панели и пункт «О программе» пока не поддерживаются этой командой.
Точность OCR зависит от отображения текста; это вспомогательная навигация,
а не исправление всех элементов Happ. Первое распознавание четырёх подписей
проверено на установленной версии. Озвучка списка и открытие «Настроек»
подтверждены пользователем; открытая страница дополнительно проверена.
Отмена и переходы в остальные разделы ещё требуют испытаний.

Сочетание можно изменить в диалоге NVDA «Жесты ввода», категория «Happ»,
пока активно окно Happ. Дополнительных настроек модуль не добавляет.

## Ограничения

В проверенной группе настроек интерфейса добавлены подписи «Язык: Русский»
и «Тема: Системная». Правило действует только при этой паре значений и проверенной
структуре группы. При другом языке, теме или расположении сохраняется штатная
озвучка: другие варианты пока не исследованы. Новые подписи ещё требуют проверки речи.

Другие безымянные кнопки, боковая панель, названия серверов и остальные страницы
пока не исправлены полностью. Не считайте этот модуль обеспечивающим полную доступность Happ.

У кнопок панели нет уникальных идентификаторов. Подпись меню определяется только
при совпадении проверенного контекста: одного поля поиска, подписанной кнопки
«Тест пинга», переключателей TUN/Прокси и двух небольших кнопок справа от поиска.
Абсолютные экранные координаты и номера Qt-типов не используются.
При отличающейся или неоднозначной структуре дополнительная подпись не назначается.
Изменение интерфейса Happ может потребовать доработки модуля.

## Удаление и сообщение об ошибке

Закройте тестовый NVDA, удалите каталог `scratchpad/appModules/happ` из его
тестового профиля и запустите NVDA снова.

Сообщая автору об ошибке, укажите версии Happ и NVDA, последовательность клавиш,
ожидаемую и фактическую речь. Не отправляйте ссылки подписок, ключи и содержимое
профилей подключения.

## Проверки

Самостоятельная логика проверяется командой `python -m unittest discover -s tests -v`.
Эти тесты не заменяют проверку в NVDA и проверку реальной озвучки.
