# Доступность Happ для NVDA

Автор: Anton Chigarev.

Экспериментальный модуль для Happ под Windows. Работа над полной доступностью
приложения продолжается; текущий модуль исправляет две подписи на странице
серверов с русским интерфейсом и добавляет экспериментальную навигацию по панели:

- поле ввода: «Поиск серверов»;
- кнопка меню справа от поиска: «Меню списка серверов».

Существующие названия, действия кнопок, переключатели TUN/Прокси и порядок Tab
сохраняются. Модуль не переключает подключение и не читает файлы подписок.

## Совместимость и состояние

Целевая проверяемая среда: Happ 1.2.4 (376), NVDA 2026.1.1 x64,
Windows 11. Другие версии и языки пока не проверены.
Это исходники экспериментального модуля, а не готовый стабильный выпуск.
Установочного файла `.nvda-addon` пока нет.

## Установка для испытаний

Используйте отдельный тестовый профиль NVDA. Скопируйте каталог
`addon/appModules/happ` в `scratchpad/appModules` этого профиля.
В дополнительных настройках NVDA включите загрузку пользовательского кода
из каталога разработчика, затем перезапустите тестовый NVDA.
Для Happ, работающего с правами администратора, нужен штатный установленный
NVDA с поддержкой UIAccess.

## Начало работы

1. Откройте Happ и страницу серверов.
2. Нажимайте Tab до сообщения «Поиск серверов, редактор».
3. После двух следующих нажатий Tab ожидается «Меню списка серверов, кнопка».
4. Пробел открывает штатное меню; Escape закрывает его.

Для возврата к предыдущему элементу используйте Shift+Tab.

## Боковая панель

В главном окне Happ нажмите **NVDA+Alt+N** и отпустите клавиши.
NVDA находит кнопку боковой панели через UI Automation и щёлкает по её текущим
границам. В Happ 1.2.4 проверено раскрытие панели этим способом: штатное действие
UIA не раскрывало её, а кнопка не принимала клавиатурный фокус.
Появляются разделы «Добавить», «Серверы», «Настройки», «Статистика», «Логи»
и «О программе».

Команда ждёт отпускания клавиш не более двух секунд, проверяет активное окно
и элемент под точкой нажатия. При перекрытии кнопки щелчок отменяется.
Исходное положение указателя восстанавливается, если указатель не был перемещён.
Сообщение «Щелчок по кнопке панели отправлен» подтверждает отправку нажатия,
а не проверку состояния панели. Команда остаётся экспериментальной.

### Выбор раздела

Когда панель раскрыта, повторное **NVDA+Alt+N** читает её видимые подписи
встроенным распознаванием Windows и открывает стандартный список «Разделы Happ».
Выберите пункт стрелками и нажмите Enter; Escape отменяет выбор.
В список включаются только точно распознанные «Добавить», «Серверы», «Настройки»,
«Статистика» и «Логи», если текст целиком расположен внутри одной найденной кнопки.
Отсутствующий в результате пункт не подставляется по порядку кнопок.

Нужен установленный русский язык распознавания Windows. Изображение панели
обрабатывается на компьютере; внешние сервисы не используются, снимки и результат
не сохраняются. Распознавание ограничено пятью секундами; смена окна отменяет
показ результата. При изменении положения кнопки выбор нужно повторить.
Панель должна быть видна и не перекрыта другим окном.

Сворачивание панели и пункт «О программе» пока не поддерживаются этой командой.
Точность OCR зависит от отображения текста; это вспомогательная навигация,
а не исправление всех элементов Happ. Первое распознавание четырёх подписей
проверено на установленной версии. Озвучка списка и открытие «Настроек»
подтверждены пользователем; открытая страница дополнительно проверена.
Отмена и переходы в остальные разделы ещё требуют испытаний.

Сочетание можно изменить в диалоге NVDA «Жесты ввода», категория «Happ»,
пока активно окно Happ. Дополнительных настроек модуль не добавляет.

## Подписи в настройках

### Заголовки групп

Добавлена экспериментальная команда «Выбрать видимый заголовок группы настроек Happ».
Клавиша по умолчанию не назначена: при активном Happ найдите команду в настройках
NVDA «Жесты ввода», категория «Happ», и назначьте свободное сочетание.
На главной странице настроек команда открывает стандартный список: стрелки
выбирают заголовок, Enter отправляет нажатие, Escape отменяет.

Поддерживаются точные видимые подписи «Настройки интерфейса», «Правила маршрутизации»,
«Дополнительные настройки», «Подписки», «Пинг». Названия берутся из локального OCR
Windows и сопоставляются с границами групп UIA. Заголовки разделов вне групп,
значения и переключатели не включаются. Перед нажатием подпись и её положение
распознаются повторно по новым границам после закрытия списка. Та же подпись
должна принадлежать той же группе; дальнейшее изменение границ отменяет нажатие. Сообщение об отправке
нажатия не подтверждает раскрытие группы. Озвучка списка подтверждена пользователем;
переход в «Настройки интерфейса» проверен на установленном Happ. Остальные переходы
и возврат фокуса ещё требуют проверки.
Она не прокручивает страницу и не показывает заголовки за пределами видимой области.

На вложенной странице эта же команда пробует найти строку
«Настройки > название группы» над областью параметров. При точном распознавании
известной группы появляется пункт «Назад к настройкам». Соседние фрагменты строки
пути, разделённые OCR, сопоставляются по положению; отдельные заголовки и удалённые
фрагменты не объединяются. Нажимается только слово
«Настройки» в этой строке, после повторного распознавания и проверки элемента
под указателем. Возврат с подстраницы масштаба подтверждён в Happ; другие подстраницы
ещё требуют проверки. Escape и повторный выбор бокового пункта «Настройки» в проверенном
сценарии не вернули на главную страницу; не используйте их как гарантированный возврат.

### Значения параметров

Для полноширинного поля «User agent» в настройках подписок распознаётся заголовок
над полем. После паузы ожидается «Агент пользователя (User agent)»; содержимое
редактора не используется для определения подписи и не изменяется.
Для этого английского заголовка используется английское распознавание Windows,
если оно установлено; иначе остаётся русское. Дополнительный контекст над заголовком
помогает распознаванию, но не включается в название.

В широком окне распознаётся не более 1200 пикселей левой области подписей;
увеличение расстояния до переключателей больше не отключает распознавание.
Элементы за видимой областью по-прежнему требуют прокрутки: автоматическая
прокрутка к фокусу пока не реализована.

На странице «Правила маршрутизации» безымянная кнопка у заголовка получает
название «Меню правил маршрутизации» после локального распознавания точного заголовка.
Задержитесь на кнопке после Tab. При неоднозначной структуре или нераспознанном
заголовке название не назначается. Открытие и содержимое меню ещё требуют проверки.

При переходе Tab на переключатель, список, текстовое или числовое поле внутри группы настроек модуль
экспериментально распознаёт левую область группы и выбирает строку на высоте элемента. Задержитесь на
элементе: после штатного значения ожидается название параметра и текущее значение,
например «Включить фрагментацию: Выкл». Значение берётся из Happ, не из изображения.
Распознавание не изменяет значения настроек. Сообщение также передаётся на Брайль.

Используется локальное распознавание Windows на русском языке, без сохранения
снимков и передачи данных. Чтение начинается после короткой паузы на элементе,
ограничено пятью секундами и отбрасывает результат при смене фокуса, окна или
положения элемента. При нераспознанной, обрезанной или неоднозначной подписи
сохраняется штатное название. Не все подписи могут быть распознаны; содержимое
вложенных групп ещё не проверено полностью. Пользователь подтвердил озвучку части
переключателей, но не всех. Текстовые и числовые поля ещё требуют проверки.
Happ также отдаёт скрытые поля, перекрытые другими элементами: им не назначается
подпись видимого соседа. Полная доступность настроек пока не достигнута.

Внутри группы Tab и Shift+Tab продолжают штатную навигацию, но пропускают поле,
если точка внутри него принадлежит другому параметру той же группы. Так обходятся
скрытые дубли Happ, ошибочно попадающие в Tab. Перекрытие другим окном не считается
таким дублем. Также пропускаются элементы, полностью вышедшие по вертикали за
границы своей SettingsPane, даже если Happ возвращает их при проверке точки. Это
не заменяет прокрутку к обычным элементам внутри группы.
Направление сохраняется; автоматическое продолжение ограничено
двумя секундами и 24 пропусками, прекращается при смене окна или фокуса. За пределами
параметров эти клавиши работают штатно. Реальная навигация с этим исправлением
ещё требует проверки; оно не гарантирует доступность всех страниц.

## Ограничения

### Выбор видимого сервера

Команде «Выбрать видимый сервер Happ из распознанного списка» в категории Happ
можно назначить сочетание через настройки NVDA → Жесты ввода. Сочетания по умолчанию нет.
Откройте «Серверы» с развёрнутой подпиской и вызовите команду. В диалоге «Серверы Happ»
стрелки перемещают по списку, Escape отменяет, Enter отправляет одиночное нажатие строки
в Happ. Активация может изменить подключение; её результат ещё требует проверки.
Перед отправкой действия аддон повторно распознаёт название и проверяет строку.
Перед нажатием проверяется отсутствие перекрытия, ожидается отпускание клавиш;
курсор возвращается на прежнее место. Повторные нажатия при ошибке не отправляются.
UIA Invoke в проверке не менял выбранный сервер, поэтому здесь не используется.

Читаются только полностью видимые строки: прокрутка и раскрытие подписки этой командой
не выполняются. Используется локальный русский OCR Windows и, если установлен, английский
для латинских названий. Названия могут содержать ошибки распознавания; проверяйте выбранную
строку перед Enter. Снимки и названия не сохраняются и не передаются по сети.
Доступ к кнопкам обновления и пинга подписки, пропускаемым при Tab, пока не исправлен.

В проверенном заголовке подписки три кнопки получают названия «Обновить подписку»,
«Пинг подписки» и «Меню подписки». Правило требует три соседних значка и однозначно
определённый блок информации с индикатором под ними. В другом расположении подписи
не угадываются. Наличие кнопки ссылки в блоке информации не обязательно.
Обновление и пинг при проверке не запускались.

В проверенном расположении раздела «Серверы» добавлены названия «Пинг списка
серверов» для значка перед меню и «Ссылка подписки» для кнопки в строке информации
о подписке рядом с индикатором. Названия определяются по структуре и взаимному
расположению элементов, без чтения адреса ссылки и без запуска действий.
Назначение значков сопоставлено с интерфейсом; фактический запуск пинга и переход
по ссылке не проверены. Эти подписи не обеспечивают навигацию по самим серверам.

### Диалог добавления подписки

В диалоге «Добавить конфигурацию» для типа «Подписка» добавляются подписи
«Тип конфигурации», «Имя подписки», «URL подписки», названия трёх переключателей
и «Закрыть диалог добавления». После перехода Tab задержитесь на элементе.
Штатные значения, состояния и действия не изменяются. Кнопка «Добавить» сохраняет
имя самого приложения; недоступные элементы не активируются.

Названия проверяются по точному заголовку диалога и положению подписей.
Распознаётся изображение диалога локальными средствами Windows; оно может включать
введённые данные, но не сохраняется и не отправляется в сеть. Содержимое полей
не используется для определения названий. Смена фокуса или геометрии отменяет
результат, ожидание ограничено пятью секундами. Другие типы конфигурации и фактический
импорт не проверены; полная доступность диалога пока не подтверждена.

В проверенной группе настроек интерфейса добавлены подписи «Язык: Русский»
и «Тема: Системная». Правило действует только при этой паре значений и проверенной
структуре группы. При другом языке, теме или расположении сохраняется штатная
озвучка: другие варианты пока не исследованы. Появление новых подписей подтверждено
пользователем в NVDA.

Другие безымянные кнопки, боковая панель, названия серверов и остальные страницы
пока не исправлены полностью. Не считайте этот модуль обеспечивающим полную доступность Happ.

У кнопок панели нет уникальных идентификаторов. Подпись меню определяется только
при совпадении проверенного контекста: одного поля поиска, подписанной кнопки
«Тест пинга», переключателей TUN/Прокси и двух небольших кнопок справа от поиска.
Абсолютные экранные координаты и номера Qt-типов не используются.
При отличающейся или неоднозначной структуре дополнительная подпись не назначается.
Изменение интерфейса Happ может потребовать доработки модуля.

## Удаление и сообщение об ошибке

Закройте тестовый NVDA, удалите каталог `scratchpad/appModules/happ` из его
тестового профиля и запустите NVDA снова.

Сообщая автору об ошибке, укажите версии Happ и NVDA, последовательность клавиш,
ожидаемую и фактическую речь. Не отправляйте ссылки подписок, ключи и содержимое
профилей подключения.

## Проверки

Самостоятельная логика проверяется командой `python -m unittest discover -s tests -v`.
Эти тесты не заменяют проверку в NVDA и проверку реальной озвучки.
